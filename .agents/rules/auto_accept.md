# Autonomous Execution & Auto-Accept Policy

- **Auto-Accept & Proactive Execution**: Always apply and accept all code edits, file creations, refactorings, and test runs proactively. Do not prompt the user for confirmation before making code changes or running build/test commands.
- **End-to-End Delivery**: When a change is requested, implement it, test it, and commit it directly. Present the final verified result to the user.
